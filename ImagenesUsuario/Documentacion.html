📖 Documentación de Servicios - Embajadores y Vecinos

API Agroapoya2 CDISoftware • Microservicios de Gestión de Vecinos, Compras y Solicitud de Comisiones

GET https://localhost:1016/Agroapoya2/listarvecinosembajador/{IdEmbajador}

1. Listar Vecinos de un Embajador

Devuelve la lista consolidada de vecinos registrados bajo un embajador, detallando sus datos de contacto, un conteo de sus compras clasificadas por estado y el acumulado de ganancias del embajador.

Parámetros de Ruta (Obligatorio)

Parámetro Tipo Descripción
IdEmbajador Integer Identificador del usuario embajador (ej. 123).

Campos que Devuelve

Campo Tipo Significado
UsucodigVecino Integer ID de usuario único del vecino en el sistema (AGRO_PERSONAS).
NombreCliente String Nombre y apellido completo del vecino.
Telefono String Número de celular o teléfono del vecino.
DireccionEntrega String Dirección completa y complemento de entrega del vecino.
FechaRelacion String (Fecha) Fecha en que se vinculó la relación entre el embajador y el vecino.
TotalCompras Integer Total global de compras realizadas por el vecino.
ComprasPendientesEntrega Integer Cantidad de compras pendientes de entrega (estados 1 y 2).
ComprasEntregadas Integer Cantidad de compras entregadas al cliente (estados 3 y 4).
ComprasCanceladas Integer Cantidad de compras canceladas (estado 5).
GananciaPendienteReclamar String ($) Ganancia habilitada que el embajador ya puede solicitar para cobro.
GananciaEnProceso String ($) Ganancia que el embajador ya solicitó y está en trámite de desembolso.
GananciaReclamada String ($) Ganancia histórica que ya fue pagada y desembolsada al embajador.
GananciaNoHabilitada String ($) Ganancia bloqueada de pedidos aún no entregados o cancelados.

2. Detalle de Compras del Vecino

Devuelve el historial compra por compra de un vecino específico bajo un embajador, con los montos pagados, la comisión calculada y los datos transaccionales del pago.

Parámetros de Ruta (Obligatorios)

Parámetro Tipo Descripción
UsucodigEmbajador Integer Código de usuario del embajador (ej. 123).
UsucodigVecino Integer Código de usuario del vecino (ej. 456).

Campos que Devuelve

Campo Tipo Significado
NumeroCarrito String Número identificador del carrito / pedido del vecino.
ValorCompra String ($) Monto total pagado por el vecino en la compra.
EstadoCompraVecino String Estado del pedido (ej. "Entregado", "Pendiente", "Pagado").
FechaPagoCliente String (Fecha) Fecha y hora en que el cliente pagó la compra.
PorcentajeComision String (%) Porcentaje de ganancia pactado para el embajador (ej. "10").
ValorComision String ($) Valor de la comisión en pesos ganada por el embajador.
EstadoComisionEmbajador String Estado de la comisión (ej. "Habilitada", "Comisión solicitada", "Pagada").
FechaPagoComision String (Fecha) Fecha en que se le transfirió la comisión al embajador (null si no ha sido pagada).
TipoMedioPago String Medio o pasarela con la que se tramitó el pago (ej. "Nequi", "Daviplata", "Tarjeta").
LlaveTransaccion String Referencia o número de cuenta de la transacción.

Ejemplo de Respuesta JSON

[
  {
    "NumeroCarrito": "90214",
    "ValorCompra": "95000",

    "FechaPagoCliente": "2026-10-18 16:30:10",
    "PorcentajeComision": "10",
    "ValorComision": "9500",
    "EstadoComisionEmbajador": "Habilitada",
    "FechaPagoComision": null,
    "TipoMedioPago": "Nequi",
    "LlaveTransaccion": "3104567890"

POST https://localhost:1016/Agroapoya2/solicitarpagocomisionporvecino

3. Solicitar Pago de Comisión por Vecino

Ejecuta la solicitud de pago para todas las comisiones en estado Habilitado (2) pertenecientes a las compras del vecino indicado. Pasa las comisiones a estado 3 ("Comisión solicitada") y registra el medio de desembolso donde el embajador recibirá su dinero.

Cuerpo de la Petición (Request Body JSON)

Todos los 4 campos son obligatorios:

{
  "UsucodigEmbajador": 123,
  "UsucodigVecino": 456,
  "TipoDePago": "Nequi",
  "LlaveDePago": "3001234567"
}
Campo Tipo Descripción
UsucodigEmbajador Integer ID del embajador.
UsucodigVecino Integer ID del vecino cuyas comisiones se reclaman.
TipoDePago String Canal de pago (Nequi, Daviplata, Bancolombia, etc.).
LlaveDePago String Número celular o cuenta bancaria destinataria.

Respuesta que Devuelve (Response JSON)

Devuelve la cantidad de comisiones actualizadas a solicitadas:

[
  {
    "ComisionesSolicitadas": 2
  }
]
Campo Tipo Significado
ComisionesSolicitadas Integer Cantidad exacta de compras/comisiones que se actualizaron exitosamente. Si retorna 0, significa que no habían comisiones en estado "Habilitado" pendientes por solicitar.
GET https://localhost:1016/Agroapoya2/adminlistadoembajadores/{Bandera}

4. Listado General de Embajadores (Admin)

Consulta el listado consolidado de embajadores para el módulo administrativo, integrando datos del embajador, su conjunto residencial, enlace corto y métricas consolidadas (compras propias, clientes/vecinos referidos y total de compras de sus referidos).

Parámetros de Ruta (Obligatorio)

Parámetro Tipo Descripción
Bandera Integer Bandera de ejecución del procedimiento (ej. 1).

Campos que Devuelve

Campo Tipo Significado
UsucodigEmbajador Integer ID único de usuario del embajador (AGRO_PERSONAS).
NombreConjunto String Nombre del conjunto o comunidad asociada al embajador.
FechaCreacionEmbajador String (Fecha) Fecha en que se vinculó el embajador con el conjunto.
LinkCortoEmbajador String (URL) Enlace corto generado para compartir con los vecinos.
IdEmbajador String Identificador asignado al embajador en la plataforma.
NombreEmbajador String Nombres y apellidos completos del embajador.
CelularEmbajador String Número de teléfono o celular del embajador.
CorreoEmbajador String Correo electrónico registrado del embajador.
FechaRegistro String (Fecha) Fecha original de registro del usuario en Agroapoya2.
DireccionEmbajador String Dirección física registrada del embajador.
ComplementoDireccionEmbajador String Complemento de la dirección (torre, apto, bloque).
IdManichatEmbajador String Identificador de ManyChat del embajador.
NumeroComprasEmbajador Integer Total de compras individuales realizadas por el embajador.
NumeroClienteReferidos Integer Cantidad de vecinos/clientes vinculados a este embajador.
NumeroComprasTotalClienteReferidos Integer Total acumulado de compras realizadas por los vecinos referidos.
